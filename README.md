# Ujani Reservoir -- Watershed Management

## Project Overview

This project focuses on reservoir water balance modelling for the Upper
Bhima Basin and Ujani Reservoir, Maharashtra.

## Data Collection

Data collection and processing are currently underway. The collected
hydrological and rainfall data will be processed and used as inputs for
the model.

## Outputs

The model will be used to generate updated results and PNG
visualizations to analyse reservoir storage, water availability, and
competing water demands. The repository will be updated as the analysis
progresses.
